# Дмитрий Ширяев — сайты и Telegram-боты за 1–3 дня

**Живой сайт:** [dmitry-shiryaev.vercel.app](https://dmitry-shiryaev.vercel.app)

Портфолио-лендинг веб-разработчика. Создание посадочных страниц, интернет-магазинов, Telegram-ботов и калькуляторов «под ключ» — с вайб-кодингом, в 2–5 раз быстрее стандартных сроков.

## Что умею

- **Лендинги и сайты** — от визитки до многостраничника с анимациями и SEO-текстами
- **Telegram-боты** — запись клиентов, ответы на вопросы, приём заявок, поддержка
- **Калькуляторы и интерактив** — онлайн-расчёт цены и срока прямо на странице
- **MVP для стартапов** — быстрый прототип продукта для проверки идеи

## Особенности сайта

- Интерактивный калькулятор стоимости и сроков (лендинг / бот / калькулятор / MVP)
- Прозрачные цены и этапы работы с дедлайнами
- Оплата по этапам 40 % / 40 % / 20 %
- Кейсы с реальными проектами и фото
- Готов к GEO: JSON-LD, sitemap, robots для AI-ботов, IndexNow

- Чистый HTML + CSS + JS без сборщиков — быстрая загрузка
